# Validation Reference

After implementation, validate at four levels.

## 1. Code
- format/lint
- typecheck
- unit/integration tests where relevant

## 2. Build/runtime
- production build
- route availability
- server/client rendering behavior
- redirects

## 3. Search
- title/meta output
- canonical output
- robots directives
- sitemap consistency
- structured data validity
- internal links
- status codes

## 4. Business
- analytics preserved
- conversion paths preserved
- forms/payment flows preserved
- no critical UX regression
