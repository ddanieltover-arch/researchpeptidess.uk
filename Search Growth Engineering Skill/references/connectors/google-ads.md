# Google Ads Connector

Use the Google Ads API for paid-search evidence when authorized. The API supports Search/SearchStream queries using Google Ads Query Language.

## Required environment
- `GOOGLE_ADS_CUSTOMER_ID`
- `GOOGLE_ADS_DEVELOPER_TOKEN`
- `GOOGLE_ADS_ACCESS_TOKEN`
- optional `GOOGLE_ADS_LOGIN_CUSTOMER_ID`

Do not fabricate CPC, CTR, spend, conversions or ROAS when the connector is unavailable.
