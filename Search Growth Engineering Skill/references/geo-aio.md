# GEO / AIO Reference

GEO/AIO means improving the probability that relevant systems can understand, retrieve, summarize and accurately associate a source with a user need.

## Evaluate
- entity clarity
- factual consistency
- source identity
- author identity
- answerability
- semantic coverage
- question coverage
- evidence quality
- unique information
- structured information
- crawl/index eligibility
- multimodal support

## Avoid unsupported claims

Never claim:
- guaranteed citation
- guaranteed inclusion in an AI answer
- a secret prompt that controls rankings
- guaranteed AI Overview visibility

## Practical outputs

Recommend:
- clear definitions
- concise answer blocks where useful
- comparison tables
- first-party evidence
- original data
- author/source context
- clear product/service facts
- strong information architecture
- relevant images/videos

Treat Google's AI search guidance as an extension of strong search fundamentals, not as permission to create search-manipulation pages.
