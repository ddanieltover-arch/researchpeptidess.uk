# SEM / ASO Reference

## SEM
Use first-party ad data when available. Evaluate:
- commercial intent
- query-to-ad relevance
- landing-page fit
- conversion tracking
- negative keywords
- geo targeting
- budget concentration
- organic/paid overlap

## ASO
Evaluate:
- app title
- subtitle/short description
- long description
- keyword relevance
- category
- screenshots
- icon
- reviews
- ratings
- localization
- competitor positioning
- web-to-app discovery

Do not invent ad economics or app-store performance.
