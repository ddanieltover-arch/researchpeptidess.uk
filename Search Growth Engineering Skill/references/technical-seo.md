# Technical SEO Reference

Audit:
- crawl access
- indexability
- HTTP status
- redirects
- canonicalization
- robots.txt
- XML sitemap(s)
- JavaScript rendering
- URL parameters
- faceted navigation
- pagination
- duplicate URLs
- orphan pages
- internal links
- metadata
- structured data
- mobile parity
- performance
- content accessibility

## Root-cause rule

Do not report symptoms as separate issues when a root cause explains them.

Example:
A rendering problem causing missing title tags and body content should be tracked as one rendering root cause plus downstream effects, not as unrelated metadata issues.

## Severity

P0 = blocks discovery/indexing or breaks core business/search paths.
P1 = high-impact search or conversion loss.
P2 = meaningful optimization opportunity.
P3 = incremental/nice-to-have.
