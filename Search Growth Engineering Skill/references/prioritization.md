# Prioritization Reference

Use a practical 1-5 score for each dimension:

impact: expected effect on search visibility or qualified acquisition
business_value: expected contribution to leads, revenue, activation or strategic goals
effort: implementation complexity
confidence: strength of evidence
urgency: severity/time sensitivity
dependency: how many other actions depend on this item

Suggested score:
priority_score = ((impact * business_value * confidence) + urgency) / max(effort,1)

Do not treat this as mathematical truth. It is a prioritization aid. Override it when a P0 issue clearly blocks the site.
