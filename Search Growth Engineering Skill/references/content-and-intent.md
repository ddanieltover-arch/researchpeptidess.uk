# Content and Search Intent Reference

For each topic determine:
- user job
- dominant intent
- stage of journey
- entities involved
- expected SERP format
- best destination URL
- commercial value
- evidence available

## Intent classes

- navigational
- informational
- commercial investigation
- transactional/local
- mixed

## Content quality checks

Prefer original, accurate, useful information with clear authorship/source context and a reason to exist beyond ranking manipulation.

Do not mass-produce near-duplicate pages. Do not create pages for every wording variant where the underlying user need is the same.
