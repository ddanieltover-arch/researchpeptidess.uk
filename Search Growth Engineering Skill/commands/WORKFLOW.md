# Search Growth Commands

## /seo-audit
Run project discovery, crawl/technical audit where a public URL is available, and connected first-party data collectors when credentials are configured. Produce evidence-backed findings and priorities. Do not edit code.

## /seo-plan
Use the latest evidence to create an implementation plan with dependencies, acceptance criteria and expected business rationale. Do not edit code.

## /seo-fix
Only implement explicitly approved scope. Run tests, rebuild, re-audit affected URLs, and report changed files plus validation.

## /geo-audit
Inspect entity clarity, factual completeness, source-worthiness, machine-readable structure and answerability. Do not claim guaranteed AI citations or rankings.

## /aio-audit
Treat AI-search optimization as an extension of strong technical/search fundamentals. Measure actual AI-search data where available; otherwise clearly label strategic hypotheses.

## /sem-audit
Use Google Ads evidence when connected. Evaluate commercial query opportunities, landing-page alignment, paid/organic overlap and tracking quality.

## /aso-audit
For mobile apps, inspect app-store metadata, conversion surfaces, reviews, localization and website/app discovery relationships.

## /seo-report
Combine current evidence, prioritized findings, implementation status, baseline deltas and remaining risks into a report.
