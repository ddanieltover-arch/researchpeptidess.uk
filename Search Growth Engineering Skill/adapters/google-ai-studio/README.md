# Google AI Studio adapter

Use Google AI Studio to evaluate the reasoning/orchestration prompts against fixed evidence fixtures. Do not treat AI Studio as the canonical storage location for credentials or client analytics.

Recommended evaluation inputs:
- project profile JSON
- crawl/audit JSON
- GSC evidence JSON
- GA4 evidence JSON
- SERP analysis JSON
- recommendation set

The model should produce structured strategy outputs while preserving the distinction between verified evidence, inference and hypothesis.
