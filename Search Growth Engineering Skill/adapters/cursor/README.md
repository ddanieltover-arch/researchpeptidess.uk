# Cursor adapter

Install/copy the skill directory into your Cursor skills location. Keep `SKILL.md` as the activation/orchestration layer and ship `intelligence/` with it when you want local deterministic collectors.

Suggested commands:
- `/seo-audit`
- `/seo-plan`
- `/seo-fix`
- `/geo-audit`
- `/aio-audit`
- `/sem-audit`
- `/aso-audit`
- `/seo-report`

Connector secrets should be supplied through the shell environment, not stored in the skill.
